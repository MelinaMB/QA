# QA Junior Bootcamp - Proyecto Banco Simulado

## 🎯 **Objetivo**
Proyecto de formación para QA Junior con aplicación bancaria real para practicar pruebas funcionales, API, seguridad, rendimiento y accesibilidad.

## 📁 **Estructura del Proyecto**
```
├── docs/                    # Documentación del proyecto
│   ├── PRD.md              # Product Requirements Document
│   ├── API_docs.md         # Documentación de API
│   └── test_plan.md        # Plan de Pruebas
├── project/                # Aplicación bancaria
│   └── bank-app/          # App Node.js + Express
│       ├── server.js       # Backend API
│       ├── public/         # Frontend HTML/CSS/JS
│       ├── package.json    # Dependencias
│       └── README.md       # Instrucciones de la app
├── reports/                # Reportes semanales de QA
│   └── week1_report.md     # Reporte Semana 1
├── test-cases/             # Casos de prueba Semana 2
│   ├── functional_tests.md # Pruebas funcionales UI
│   └── api_tests.md        # Pruebas API endpoints
└── templates/              # Plantillas QA
    └── qa_bootcamp.md      # Guía del bootcamp
```

## 🚀 **Inicio Rápido**

### **1. Instalar dependencias**
```bash
cd project/bank-app
npm install
```

### **2. Iniciar servidor**
```bash
npm start
```

### **3. Acceder a la aplicación**
- URL: http://localhost:3000
- Usuario: `user1` / Contraseña: `pass1`
- Usuario: `user2` / Contraseña: `pass2`

## 🔄 **Semana 2 - Próximos Pasos**

### **¿Qué hacer ahora?**
1. **Leer la guía completa:** `test-cases/README.md`
2. **Ejecutar aplicación:**
   ```bash
   cd project/bank-app
   npm start
   ```
3. **Ejecutar pruebas funcionales:** Seguir `test-cases/functional_tests.md`
4. **Ejecutar pruebas API:** Seguir `test-cases/api_tests.md`
5. **Crear reporte:** `reports/week2_report.md`

### **Herramientas para testing:**
- **UI:** Navegador web (Chrome/Firefox)
- **API:** Postman, Thunder Client, o curl
- **Documentación:** Editor de texto con soporte Markdown

## 🛠️ **Herramientas Requeridas**
- Node.js (versión 16+)
- Navegador web (Chrome/Firefox)
- Git (para versionado)
- Editor de código (VS Code recomendado)
