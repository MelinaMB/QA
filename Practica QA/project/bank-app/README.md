# Banco Simulado Web

Aplicación web simple para simular operaciones bancarias básicas.

## Instalación
1. Instalar Node.js.
2. Clonar el repositorio.
3. Ejecutar `npm install`.
4. Ejecutar `npm start`.
5. Abrir http://localhost:3000 en el navegador.

## Usuarios de Prueba
- user1 / pass1 (saldo inicial: $1000)
- user2 / pass2 (saldo inicial: $500)

## Funcionalidades
- Login
- Ver saldo
- Transferencias
- Historial de transacciones
